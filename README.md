# AI ML Lab

This repository contains the practical programs completed as part of the **Artificial Intelligence & Machine Learning Lab at my university**.

Each practical is implemented in **Python** and maintained as an individual program for easy reference, learning, and submission.

## Programs

| No. | Program              | File             |
| --- | -------------------- | ---------------  |
| 01  | Breadth First Search | `bfs.py`         |
| 02  | A* Algorithm         | `A-Star.py`      |
| 03  | Tic Tac Toe          | `Tic-Tac-Toe.py` |


A simple interface for viewing the programs and their outputs is also hosted [over here.](https://aiml-lab.streamlit.app/)
